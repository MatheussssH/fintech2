# 🏦 Fintech - Sistema de Gestão Bancária e Filas em JavaScript
Projeto focado na implementação de conceitos fundamentais de **JavaScript**, **Programação Orientada a Objetos (POO)** e **Estruturas de Dados**, simulando operações de uma conta corrente e gestão de atendimento ao cliente num contexto bancário/fintech.

## 📌 Conteúdo do Projeto

- **Conta Corrente (`conta-corrente.js` & `app.js`):**
  - Orientação a Objetos (Classes, Construtor e Atributos).
  - Métodos para consulta de saldo (`consultarSaldo`) e depósitos (`depositar`).
  - Instanciação de contas e manipulação de saldos de clientes.

- **Fila de Atendimento (`atendimento.js`):**
  - Implementação de estrutura de dados de fila (*FIFO - First In, First Out*).
  - Manipulação de arrays utilizando o método `.shift()` para processar o atendimento de clientes em ordem de chegada.

- **Iteração e Repetição (`Forof.js`):**
  - Utilização do laço `for...of` para percorrer e exibir listas de clientes cadastrados.

## 🛠️ Tecnologias
- JavaScript (Node.js / ES6 Modules)
